# ☕ Mi Barista Imusa

**La guía completa para tu cafetera Imusa Café City**

## 🎯 Características

- **Calculadora Inteligente** - Cantidad exacta de café usando la cuchara dosificadora Imusa
- **Más de 300 Recetas** - Organizadas por categorías: Colombianos, Lattes, Mochas, Frappés, etc.
- **Temporizador** - Cronómetro integrado con sonido
- **Conversor** - Mililitros, gramos, cucharadas, cucharaditas, onzas, tazas
- **Favoritos** - Guarda tus recetas preferidas
- **Historial** - Últimas recetas vistas
- **Guías** - Limpieza, descalcificación, conservación, espuma, jarabes
- **Marcas Colombianas** - Juan Valdez, Sello Rojo, Águila Roja, Oma, etc.
- **PWA** - Instalable como aplicación, funciona offline
- **Modo Oscuro/Claro** - Con diseño Material Design
- **Responsive** - Optimizado para móviles y escritorio

## 🚀 Instalación

### GitHub Pages
1. Clona este repositorio
2. Sube todos los archivos a tu repositorio de GitHub
3. Activa GitHub Pages en la configuración del repositorio
4. ¡Listo! La aplicación estará disponible en `https://tusuario.github.io/mi-barista-imusa`

### Local
1. Descarga todos los archivos
2. Abre `index.html` en tu navegador
3. ¡Doble clic y listo!

## 📱 Uso

### Calculadora
1. Selecciona la cantidad de agua (100-600 ml)
2. Elige la intensidad: Suave, Normal o Fuerte
3. La aplicación calcula automáticamente:
   - Cucharas dosificadoras Imusa
   - Gramos de café
   - Cafeína aproximada
   - Azúcar recomendada
   - Tiempo de preparación

### Recetas
- Busca por nombre, ingrediente o país
- Filtra por tipo: instantáneo, molido, colombiano, frío, caliente, dulce, sin azúcar, vegano
- Cada receta incluye: foto, ingredientes, tiempo, dificultad, paso a paso, consejos y variantes

### Temporizador
- Presets de 1 a 5 minutos
- Iniciar/Pausar/Reiniciar
- Alarma sonora

### Conversor
- Convierte entre: ml, gramos, cucharadas, cucharaditas, onzas, tazas
